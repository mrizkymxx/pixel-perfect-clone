# 🗂️ PPIC Dashboard (Stock & Material)

Dashboard **PPIC** (Production Planning & Inventory Control) — pantau stok, import data, dan riwayat pergerakan material.

## ✨ Fitur

- 📊 **Dashboard stok** — gambaran stok material saat ini
- 📥 **Import** — import data stok/material
- 🕘 **Riwayat** — riwayat pergerakan produk & material

## 🛠️ Tech Stack

- **Frontend:** React + TypeScript (TanStack Start/Router), Tailwind CSS, shadcn/ui
- **Backend/DB:** Supabase (PostgreSQL)
- **Deployment:** Vercel / Cloudflare (wrangler)

## 🗂️ Routes

`/` (dashboard) · `/stok` · `/import` · `/riwayat`
